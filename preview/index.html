Arduino LCD 文字動畫互動系統

基於 Arduino Uno R3、1602 LCD 與 Digital Push Button v3 的全動態文字動畫模擬器。
支援 6 種文字動畫模式，非阻塞 millis() 即時響應，可點擊下方按鈕實時測試！

ARDUINO UNO R3 • COM3 CONNECTED
I2C: 0x27 | PIN 2
HD44780 COMPATIBLE 1602 LCD SPEED: 1X (NORMAL)
🔘 DFRobot Digital Push Button v3
👉 短按：切換下一種動畫模式（循環 0 ~ 5）
⚡ 長按（按住 > 1秒）：切換 1X正常 / 2X加速 播放！
🎭 動畫模式選單
⚙️ 模擬器設置
LCD 背光色調 經典藍底白字
動畫運算速度 1X 標準速度
模擬按鈕防抖時間 40 ms

🔌 實體硬體接線說明 (Pinout)

  • I2C 1602 LCD:
    GND ➔ Arduino GND
    VCC ➔ Arduino 5V
    SDA ➔ Arduino A4 (或板端專用SDA腳位)
    SCL ➔ Arduino A5 (或板端專用SCL腳位)
  • Digital Push Button v3:
    D / OUT (綠線/黃線) ➔ Arduino Digital Pin 2
    + / VCC (紅線) ➔ Arduino 5V
    - / GND (黑線) ➔ Arduino GND

💡 程式設計與互動藝術特色

  • 非阻塞式架構：全程式使用 millis() 狀態機，完全捨棄 delay()，保證按鈕隨時點擊都能毫秒級響應。
  • 8組自訂 5x8 像素：透過 lcd.createChar() 刻畫出心跳律動與 4 階音頻等化器動態頻譜。
  • 藝術敘事結合：黑客解碼、打字機對話、雙向文字流，完美切合 ATB507 互動科技與創意編程主題！
